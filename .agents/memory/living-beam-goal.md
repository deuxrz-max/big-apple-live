---
name: Living Beam rooms
description: The user's product goal for automatically active Beam rooms.
---

The user's goal: "have every beam room to seem as if its a living organism, where events start automatically."

**Why:** The user stated this as the intended experience for every Beam room.

**How to apply:** Use this goal when shaping room activity and automatic events.

For the initial living-room experience, the user chose "Visual moods only," not prompts, polls, or group challenges.

**Why:** This was the user's explicit selection when asked which automatic events to start with.

**How to apply:** Keep automatic events visual unless the user requests interactive activities later.
