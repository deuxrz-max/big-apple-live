name: User-facing room terminology
description: Call the app's communities rooms, never universities; preserve internal identifiers.
---

Use “room” / “rooms” rather than “university” / “universities” in all user-facing app copy, including accessibility labels, rules, notifications and server errors.

**Why:** The owner explicitly requested replacing all visible variants throughout Deux Wild, including the Following empty state.

**How to apply:** Apply to new copy and error paths as well as normal screens. Keep grammar natural. Do not rename internal routes, identifiers, CSS classes, asset paths or hash prefixes as a terminology-only change; those are stable functional contracts, not visible app copy.
