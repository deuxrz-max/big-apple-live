---

Use TalkCity as a functional reference, not as a brand or website to duplicate. Add the selected functionality alongside existing Beams and retain We Buggin's theme and branding.

**Why:** The user chose “Add alongside Beams” and clarified: “I dont want it to be talkcity. I want my site to mimic it in some ways”.

**How to apply:** Build additional capabilities without replacing the existing Beam experience or importing TalkCity's branding, promotional claims, or user population.

The selected expansion is discovery/social functionality and credits, gifts and rewards—not random camera or voice matching.

**Why:** The user selected those two feature groups and did not select either random-matching mode.

**How to apply:** Do not introduce a matching queue, camera capture, or stranger-call experience as part of this expansion.

Community discovery must be opt-in for existing accounts.

**Why:** Adding a public social directory is not permission to expose identities previously used only in Beams.

**How to apply:** Keep new social profiles undiscoverable by default; allow the account holder to choose visibility explicitly.
