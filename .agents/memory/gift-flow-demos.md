**Why:** The user approved this phone-sized Spirit Pup gift recording as a clear demonstration.

**How to apply:** When asked to show a gift interaction and authenticated preview access is unavailable, capture the real component flow in the test harness rather than creating a static mockup, and disclose the fixture boundary.
