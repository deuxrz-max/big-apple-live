The active product scope and financial constraints are in `replit.md`. Earlier
Beam notes are archived references; this note records optional follow-on rules.

Any optional ownership check must use a temporary unique bio code and a real
reviewer check where the external profile can actually be inspected; it is not
official platform verification.

**Why:** The user explicitly rejected matching names, links or screenshots as
proof and required no badges without a completed check.

**How to apply:** Screenshots/links alone are insufficient. Label completed
checks “ownership checked by We Buggin,” not official verification. Do not award
an ownership badge before the check is completed or invent platform APIs.
