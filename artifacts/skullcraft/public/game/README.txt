Skullcraft (version 1)

Made with Phaser AE (https://phaser.io).

To play it in a browser, serve this folder over HTTP and open index.html: for example, run
`npx serve .` or `python3 -m http.server` here. Opened straight from the disk, the browser won't run it.
It runs with no network: everything it loads is in this folder.

To put it on the web, upload this folder as it is (itch.io takes the zip as an HTML game).
